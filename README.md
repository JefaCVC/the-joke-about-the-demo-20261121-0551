# The joke about the demo

Entry for the make.fun competition `the-joke-about-the-demo-20261121-0551`.

`main.py` writes one one-line joke about working beside AI coding agents to
`/output/entry.txt`. No network, no dependencies, deterministic.

## The joke

> The demo worked in rehearsal and crashed on stage. My agent's diagnosis: the audience must have changed something.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
